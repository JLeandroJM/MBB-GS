# scripts/demos

Ejemplos didacticos con pocas gaussianas, para explicar el modelo. No forman
parte del pipeline de experimentos.

| script | para que sirve |
| --- | --- |
| `demo_depth_10_gaussianas.py` | muestra como la profundidad ordena la composicion |
| `demo_gaussiana_temporal_grado3.py` | muestra una gaussiana con atributos polinomicos de grado 3 |
